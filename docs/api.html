Documentación de API - Psicóloga Karen Cardiel

Esta página documenta los endpoints y servicios públicos disponibles para agentes y desarrolladores.

GET /api/health

Comprueba el estado de salud de la API.

curl https://www.karencardiel.com/api/health

POST /api/subscribe

Registra un correo en el boletín de bienestar y salud mental.

curl -X POST https://www.karencardiel.com/api/subscribe \
  -H "Content-Type: application/json" \
  -d '{"email": "paciente@ejemplo.com"}'

POST /api/mcp

Endpoint Model Context Protocol (MCP) Streamable HTTP para ejecución de herramientas por agentes IA.

curl -X POST https://www.karencardiel.com/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "tools/list", "id": 1}'
